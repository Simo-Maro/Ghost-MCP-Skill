# Contributing to Ghost-MCP-Skill

Thank you for your interest in `Ghost-MCP-Skill` (`ghost-cms-mcp` and the `ghost-writing` skill)!

## Issues-Only Contribution Policy (No Public Pull Requests)

This repository accepts **GitHub Issues only** — we do **not** accept public Pull Requests.

If you encounter a bug, have a feature idea, or want to suggest an improvement to `ghost-cms-mcp` or the `ghost-writing` skill, please open a clear, detailed Issue on GitHub:
https://github.com/Simo-Maro/Ghost-MCP-Skill/issues

### What to Include in a Bug Report
- Ghost version (e.g., `6.77.0-alpine`), Node.js version, and OS
- MCP client used (Antigravity, Claude Code, Codex, OpenCode, etc.)
- Steps to reproduce and the exact error message
- **Never** paste your real `GHOST_ADMIN_API_KEY` or private `.env` contents into an Issue

### What to Include in a Feature Request
- The workflow or publishing problem you are trying to solve
- Whether it fits within our content-focused scope (Sites, Posts, Pages, Tags, Feature Images/media, and Readiness Audits). Members, Newsletters, Invites, Tiers, Users, Offers, Roles, Webhooks, site-wide Settings writes, and Theme management are intentionally out of scope.
